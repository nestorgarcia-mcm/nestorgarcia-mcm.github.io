02

Five blocks

What I built and use every day. Figures come from my own registers.

1 · DOCUMENT CONTROL

Coded register with revision history

  • 12 document types with their own codes, like a project MDR
  • 250+ documents, 440+ revisions, each with date, reason and author
  • Folder template and renaming by project; 18,910 documents indexed
  • MDR template and a document control procedure in English and Spanish
→ Rev. 0 = first issue · old versions to Obsolete
2 · PROCEDURES

Drafted with AI, reviewed by me

  • 214 existing procedures inventoried in 15 types
  • 19 discipline procedures: piping, welding, NDT, testing, flushing
  • Each with an A4 one-page summary for the crews
  • Technical review before issue: codes, hold points, site reality
→ 6 h of drafting becomes 30 min of review
3 · EMAIL

Triage by rules, every action logged

  • 11 folders, 26 sub-labels, 20 filters
  • 191 senders mapped in an editable table
  • Daily summary; only what needs me stays in the inbox
  • Every move recorded with its own code · 758 emails classified so far
→ 137 threads filed in one pass
4 · REPORTS AND DATA

A report that builds itself

  • About 160 fields recalculated every hour
  • SQLite database of projects, documents and tenders
  • 91 vacancies analysed with priority and risk flags
  • Dashboard that opens on a PC or a phone
→ 60 min by hand becomes 5 min of review
5 · INFRASTRUCTURE

Tools wired together

  • About 40 automations and skills of my own
  • A control deck with 55+ one-touch actions, also from the phone
  • Connected: email, cloud drive, Notion, n8n, a local knowledge base
  • Daily backup to a separate disk
→ sources → AI and automations → register, reports, dashboard

05

How the result is controlled

Automation is only useful on a project if every result can be traced and checked.

One code per documentand one row per revision: Rev., date, reason, author.
Every email action loggedwith its own code, so any move can be traced.
Originals never overwrittennew versions alongside, old ones to an Obsolete folder.
AI drafts, I approvetechnical responsibility stays with the engineer.
Client systems stay the masterworks alongside Aconex, Procore or the client's EDMS.
Daily backup, no client data publishedeverything shown here is my own or anonymised.
